# Speak Japanese

A speak-only, 10-week course in travel Japanese that runs entirely in the browser: a daily guided session, listening and conversation drills, a phrasebook and translator, flashcards, and a planner that adapts when you miss days.

Open it: https://majidbehroz-rgb.github.io/speak-japanese/

On a phone, add it to the home screen (Safari: Share → Add to Home Screen; Chrome: menu → Add to Home screen). Progress is saved on each device.

Everything is in `index.html`; no build step, no server, no account.
